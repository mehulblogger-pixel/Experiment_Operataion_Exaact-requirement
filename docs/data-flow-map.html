Inspection Operations · Demo Dataset

Lead → Money

How one order threads through the whole application — from the first enquiry to cash in the bank — and every register that branches off it. This is the map of the demo data: 200 of 207 tables populated, all anchored to one company, all interlinked, each screen showing a real, connected figure.

200 / 207 tables seeded 83 registers tracked 12 thread stations clients: Narmada · Suryavan · Girnar · Kutch offices: Ahmedabad · Mumbai · Pune

Roughly half of these rows are deliberate edge cases. A register full of tidy, compliant rows proves nothing — you cannot tell a working gate from a missing one.
